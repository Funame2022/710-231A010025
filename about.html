Phần Lý thuyết & Giải thích Logic

Bài 1: Tìm kiếm sản phẩm

Logic: Khi người dùng gõ từ khóa, không tìm ngay lập tức mà chờ 300ms (tránh lag). Lọc sản phẩm bằng cách chuyển tên về chữ thường rồi kiểm tra từ khóa có trong đó không. Input được làm sạch (loại ký tự đặc biệt như < >) tránh lỗi hiển thị code HTML nguy hiểm. Không tìm thấy → hiện thông báo.

Bài 2: Form validation & LocalStorage

Logic: Khi nhấn submit, chặn trang reload để xử lý JS. Lấy dữ liệu form (làm sạch tên, kiểm tra email đúng định dạng, mật khẩu đủ mạnh). Lưu vào LocalStorage dưới dạng danh sách JSON. Bảo mật: Mật khẩu lưu dạng text (demo), thực tế mã hóa trước khi lưu. Trang users.html đọc list để hiển thị/sửa/xóa (luôn persist).

CRUD users.html: JSON.parse load list → map HTML cards (sanitize display, masked password). Edit: modal form re-validate → replace index. Delete: splice(index,1) → stringify/save. Persist across tabs/sessions.

Bảo mật LocalStorage: Demo plain password (client-only), prod: crypto.subtle.digest('SHA-256', password) hash trước save. Sanitize tất cả display tránh XSS. No server sync → local only.

Bài 3: Countdown timer

Logic: setInterval chạy mỗi giây trừ thời gian còn lại, hiển thị MM:SS. Dưới 1p đổi màu đỏ rung. Hết giờ tự dừng (clearInterval) hiện popup. Khi đóng tab cũng dừng để tránh chạy ngầm tốn RAM. Deploy hosting: Lấy thời gian server thay vì client (tránh chỉnh giờ máy).
